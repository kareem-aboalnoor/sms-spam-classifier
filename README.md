# 📩 SMS Spam Classifier

A simple **Streamlit web app** that classifies SMS messages as **Spam** or **Ham** (Not Spam) using a **Multinomial Naive Bayes** model trained on the **SMS Spam Collection Dataset**.

---

## 🚀 Features
- Classifies messages as **Spam** or **Ham** in real-time.
- Clean and simple user interface with Streamlit.
- Pre-trained **Multinomial Naive Bayes** model.
- Built with **Python, scikit-learn, and joblib**.

---

## 📊 Dataset
The model was trained on the public dataset:  
**[SMS Spam Collection Dataset](https://archive.ics.uci.edu/ml/datasets/sms+spam+collection)**  
- 5574 messages in total  
- Labels: `ham` (legit) and `spam` (unwanted messages)
